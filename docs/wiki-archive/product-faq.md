# 智能客服产品手册

## 产品概述
本产品是面向电商与 SaaS 行业的多渠道客服系统，支持网页、App、微信公众号、抖音私信等渠道统一接入，核心能力为意图识别、多轮对话管理与人机协同转接。

## 版本与定价
灵犀智能客服分三档：基础版每月 999 元（3 个坐席、每月 5000 次对话额度）；专业版每月 2999 元（10 个坐席、每月 30000 次对话额度，支持自定义知识库与 API）；企业版按需报价（不限坐席，支持私有化部署与专属模型微调）。超出对话额度部分按 0.3 元/次计费，年付享 8.5 折。

## 接入与部署
SaaS 版本 1 个工作日内可完成渠道接入，只需在管理后台获取渠道密钥并配置 Webhook。私有化部署要求最低 8 核 32G 服务器一台加 GPU（可选，用于本地模型推理）。数据存储支持 MySQL 与 PostgreSQL。

## 常见问题
- **对话额度如何计算？** 一次连续会话（30 分钟内无新消息视为结束）计为一次对话，转人工不额外计费。
- **支持哪些大模型？** 专业版以上支持接入 OpenAI 兼容接口，内置默认模型为通义千问。
- **如何导出会话记录？** 管理后台「数据报表」支持按时间范围导出 CSV，企业版可开通 API 实时拉取。

## 服务等级承诺 SLA
可用性承诺 99.9%，故障响应时间 30 分钟内，重大故障 4 小时内提供临时解决方案。每月发布服务报告。
