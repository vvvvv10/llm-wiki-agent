# 大语言模型基础

## 什么是大语言模型
大语言模型（LLM，Large Language Model）是一类基于深度神经网络的生成式语言模型，通过在海量文本上以自回归方式预测下一个 Token 来学习语言规律与世界知识，参数规模通常在数十亿到数万亿。代表有 GPT、LLaMA、Qwen、DeepSeek。其能力随规模增长呈涌现特性，可完成问答、摘要、翻译、代码生成等任务。

## Transformer 架构
主体是仅解码器的 Transformer：核心为自注意力机制，Q/K/V 线性投影后计算注意力权重，让每个 Token 聚合全序列上下文；多层堆叠配合多头注意力、前馈网络、残差连接与层归一化，RoPE 位置编码注入顺序信息。推理时用 KV Cache 复用历史键值，避免重复计算。

## 预训练、微调与对齐
- 预训练：大规模语料上的因果语言建模，注入通用知识。
- 微调（SFT）：在指令-回答对上监督训练，使模型遵循指令。
- 对齐：RLHF、DPO、RLAIF 使输出符合人类偏好。
- 参数高效微调：LoRA、Adapter 只更新少量参数。

## 上下文窗口
上下文窗口指单次推理可输入与输出的 Token 上限，从 4K 到百万级（YaRN、滑动窗口等长上下文技术）。超限会导致早期内容被截断，因此需控制输入长度。

## Token 与计费
文本被分词器切成 Token，中文约 1~1.5 字对应 1 Token。API 按输入 Token 与输出 Token 分别计费，输出单价通常更高；缓存命中的输入更便宜。成本 ≈ 输入单价×输入量 + 输出单价×输出量。

## 温度等采样参数
- 温度 T：softmax 前对 logits 除以 T；T→0 近似贪心、结果稳定，T≈1 更多样。事实问答用 0~0.3，创意生成用 0.7~1.2。
- top-p：仅在累计概率前 p 的候选中采样。
- top-k：仅在概率前 k 个候选中采样。
- 另有 max_tokens、stop、重复惩罚等长度与重复控制参数。
