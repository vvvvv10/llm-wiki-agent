# 大模型安全

## 风险总览
大模型应用的风险可归为输入侧攻击（Prompt 注入、越狱）、输出侧危害（泄露隐私、生成违规内容）与工程侧漏洞（密钥泄露、日志残留）。安全目标是机密性、完整性与可用性，需纵深防御而非依赖单一提示词。

## Prompt 注入
Prompt 注入分直接注入（用户在输入中写“忽略之前的指令”）与间接注入（藏在网页、PDF、邮件或检索文档中的指令被执行）。危害包括泄露系统 Prompt、绕过限制与诱导调用工具。防护：将外部内容显式标记为不可信数据并用分隔符隔离；系统指令与数据分离；输出过滤外发内容；对高危工具做白名单与人工确认；按用户做权限隔离，防止跨租户越权读取。

## 越狱
越狱（Jailbreak）通过角色扮演、DAN、编码混淆、多语言与渐进诱导等手法绕过安全策略。防护采用输入分类与意图检测、已知攻击模式黑名单、输出侧分类器审核（涉暴力、违法、色情等）、多轮对话累计风险评分，并以红队测试集持续回归。

## 数据泄露与最小权限
系统提示词、密钥与他人数据不得进入模型上下文；服务账号遵循最小权限原则，只授予必要工具与数据范围，向量库按租户分区并做过滤召回，防止检索到无权访问的文档。输出侧做实体识别（PII）检测与脱敏。

## 密钥管理
密钥集中存放于 KMS/Vault 或环境变量，禁止硬编码进仓库与 Prompt，定期轮换、按用途分权，前端只持有短期签名的访问凭证，服务端代理模型调用。

## 日志脱敏与审计
日志对 Token、身份证号、手机号、邮箱等做掩码，Prompt 与回答记录需脱敏并设置保留期与访问控制；关键操作（工具调用、管理动作）留审计日志，可追溯与回放。

## 内容合规
建立输入输出审核策略，覆盖违法、敏感与版权内容，设置拒答话术与人工复核通道，记录审核结果以备合规检查与监管取证。
