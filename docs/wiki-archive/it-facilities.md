# IT 设备与账号管理指南

## 电脑领用与归还
新员工入职当天在 IT 服务台领取笔记本电脑，标准配置为 MacBook Pro 14 寸或同级 Windows 机型。领用需签署设备责任书。离职时需提前 3 个工作日归还全部设备，IT 检测确认无损坏后办理离职手续，设备损坏按折旧价赔偿。

## 软件申请
常用办公软件（Office 365、企业微信、飞书、JetBrains 全家桶）可直接在 IT 自助门户申请。特殊专业软件需部门总监审批，版权费用由部门预算承担。禁止安装破解软件，一经发现按违规处理。

## 账号与权限
- 邮箱与 OA 账号：入职自动开通，格式为「姓氏拼音.名字拼音」。
- 代码仓库权限：向直属上级申请，仓库负责人审批后开通。
- 数据库生产库权限：需填写数据安全申请单，DBA 审批，默认只读，写权限限运维窗口操作。
- 离职账号在离职当天统一禁用，邮箱保留 90 天后删除。

## 网络与 VPN
办公区连接 WiFi「Company-5G」，密码每季度更换。远程办公使用公司 VPN，客户端在 IT 自助门户下载，双因子认证（密码 + 令牌）。VPN 同时连接上限为 3 台设备。

## 常见问题
- **忘记密码怎么办？** 在 IT 自助门户点击「找回密码」，通过手机验证码重置；域账号需联系 IT 服务台。
- **电脑故障如何报修？** 企业微信搜索「IT 服务台」机器人，描述问题并附照片，工程师 4 小时内响应。
- **打印不了怎么办？** 确认已安装对应打印机驱动（IT 门户下载），或换一台打印机重试；持续失败联系 IT。
